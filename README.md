# Novo Tempo Engenharia

Website institucional desenvolvido para uma empresa do segmento de engenharia, com foco em apresentação profissional, organização das informações e experiência do usuário.

## 📋 Sobre o projeto

O projeto consiste no desenvolvimento de um website institucional para a Novo Tempo Engenharia.

A proposta foi criar uma presença digital profissional para a empresa, utilizando uma interface moderna, responsiva e organizada para apresentar sua identidade e seus serviços.

O projeto também foi uma oportunidade de aplicar conhecimentos de desenvolvimento web moderno, componentização e estilização responsiva utilizando o ecossistema React/Next.js.

---

## 🎯 Objetivos

- Criar uma presença digital profissional para a empresa
- Organizar as informações de forma clara para o usuário
- Desenvolver uma interface responsiva
- Aplicar boas práticas de desenvolvimento web
- Utilizar tecnologias modernas do ecossistema React
- Realizar o deploy da aplicação em ambiente de produção
